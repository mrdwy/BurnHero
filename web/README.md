# 燃脂勇者 · 网页版 v0.1

像素风、游戏任务驱动的减肥 Web 应用（PWA）。React + TypeScript + Vite，数据存在浏览器本地。

## 运行（Windows / Mac / Linux 都一样，需要 Node.js 18+）

```bash
cd web
npm install
npm run dev        # 开发模式，终端会显示 Local 和 Network 地址
```

- 电脑上打开 `http://localhost:5173`
- 手机和电脑连同一个 Wi-Fi，手机浏览器打开终端里的 Network 地址（如 `http://192.168.1.5:5173`）

正式运行：

```bash
npm run build
npm start          # http://localhost:8080 ，PORT 环境变量可改端口
```

## 大模型

第一次进入填写 API 地址、Key 和模型后直接保存，不做连接测试或内容审核。已移除演示结果及计划的假数据回退。到「角色 → 设置」也可以更新配置：

- API 地址：OpenAI 兼容地址，例如 `https://api.openai.com/v1`、`https://dashscope.aliyuncs.com/compatible-mode/v1`
- API Key
- 模型：**必须能看图**（餐饮照片、手环截图要用），例如 `gpt-4o-mini`、`qwen-vl-max`

很多大模型 API 不允许浏览器直接调用，所以请求先发到本机服务（`/api/llm`，见 `llm-proxy.mjs`），再转发到你填的地址。Key 只存在你的浏览器里。

图片请求需要上游模型支持视觉输入。应用只转发请求并显示上游回复；实际网络或接口错误会直接显示，不会自动替换成演示计划。

## 使用流程

1. 填写 API 地址、Key 和模型，直接保存继续，不先发送连接审核请求。旧版本角色/奖励保留。
2. 上传截图后将原始图片作为 data URL 直接发送给模型，不限制报告类型、日期、文件大小或测量范围。不要求人工审核、核对或勾选；模型返回自然语言或 JSON 都直接展示，不因缺失某个测量字段阻止继续。
3. 身体状况、睡眠与可运动时间不设必填、长度和数值范围限制，输入原样传入后续模型请求。可以不上传或不补充而继续；已记录资料跨日复用，不强制每天重传。原图不写入 localStorage，只保存模型回复及输入。
4. 新角色可以补充昵称、身高、年龄、性别、目标体重等资料，不再做范围审核；模型恰好返回结构化测量值时可用于预填。
5. 计划页直接显示 LLM 原始回复，不要求特定 JSON 格式。若模型同时返回可识别的游戏任务结构，会额外显示任务；自然语言建议不需要接受任务即可阅读。更新资料会使旧计划失效，已领取奖励保留。

餐饮热量、日常体重也不再设应用侧数值范围门槛；游戏金币、领奖等原有状态规则仍保留。模型服务自身的能力、网络和接口错误不由应用侧绕过。

指令与调用实现在 `src/llm.ts`；身体评估结构定义在 `src/types.ts`。
