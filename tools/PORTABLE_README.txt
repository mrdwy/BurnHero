燃脂勇者 Windows 便携测试版 v0.1

适用：Windows 10/11，64 位（x64）。这是电脑版浏览器测试包，不是安卓 APK。
无需安装 Node.js，也无需 npm install。

【开始测试】
1. 将整个 ZIP 解压到一个普通文件夹，不要在压缩包内直接运行。
2. 双击“启动测试.cmd”。
3. 保持黑色服务窗口打开，浏览器会自动打开 http://127.0.0.1:18080/ 。
4. 如果浏览器未自动打开，手动复制上述地址打开。
5. 测试结束时关闭服务窗口即可停止。只关浏览器不会停止服务。

【配置与流程】
- 需要联网使用自己的 API 地址、API Key 和支持图片的模型；包内不含任何测试者或开发者的 Key。
- API 为 OpenAI 兼容格式，基础地址通常以 /v1 结尾。填写后直接保存，不强制连接测试。
- 上传报告截图和输入身体状况后，应用会发给你配置的模型服务。网络/模型调用可能产生费用。
- 应用直接展示 LLM 回复，不审核报告类型、日期、测量范围或回复格式。
- 自然语言回复可以直接阅读；模型返回游戏任务结构时，还会显示可领取的游戏任务。
- 数据和 API Key 保存在当前电脑、当前浏览器、这个地址的 localStorage。
- 原始截图不保存进 localStorage；模型回复及输入记录会保存在本机。

【数据与升级】
- 首次测试使用空数据。开发者电脑的角色、照片、记录和 API Key 均不在本包中。
- 不要清理浏览器数据，否则角色和记录可能丢失。需要时在“角色→设置”导出备份。
- 同一台电脑、同一浏览器、同一地址测试时，记录可以保留。换浏览器、端口或电脑不会自动同步。
- 端口18080已被占用时，会提示关闭旧测试窗口，不会自动更换端口造成数据看似丢失。
- 服务只监听本机回环地址，不会开放给同一 Wi-Fi 下的其他设备。
