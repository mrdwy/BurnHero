# 燃脂勇者 · 像素风 UI 风格指南 v0.2

> 一款「像打游戏一样减肥」的安卓 App：大模型每天生成减肥计划 → 拆成任务 → 完成任务获得战力、经验、金币、装备。
> 风格关键词：**16-bit 复古 RPG 菜单 / 硬边像素 / 有限色板 / 几乎不做动画**。

效果图在 `design/mockups/`，生成提示词在 `design/prompts/`（`_style.txt` 是所有页面共用的风格前缀）。

## 2. 字体

- **中文**：[Fusion Pixel Font 缝合像素字体](https://github.com/TakWolf/fusion-pixel-font)（12px 版，OFL 开源可商用）或 [Ark Pixel 方舟像素字体](https://github.com/TakWolf/ark-pixel-font)。
- **数字 / 英文**：同一套字体即可；大数字（战力、体重）用 2× 或 3× 整数倍放大。
- 字号只用像素字体基准尺寸的**整数倍**：12 / 24 / 36（dp 按设备密度换算后取整到物理像素），避免半像素糊边。
- 关闭字体抗锯齿（Compose 中用 `FontFamily` + 位图字体 / 或 TTF 像素字体在整数倍尺寸下渲染）。

## 3. 像素规则

- 基础网格 **4dp**，所有间距、圆角都是 4 的倍数。
- 不用真圆角：面板四角各"切掉"1 个像素块，营造像素圆角。
- 面板 = `panel` 填充 + 2px `outline` 描边 + 左上 1px `panelHi` 高光 + 右下 2px `outline` 投影。
- 禁止：渐变、模糊、半透明阴影、矢量平滑曲线。遮罩层用 `outline` 70% 不透明度纯色。
- 图标源网格：普通图标 **32×32**，角色 / 场景 / 宝箱 **64×64**（BOSS 头像 48×48），按整数倍放大（`FilterQuality.None` / 最近邻采样）。

## 4. 组件

| 组件 | 规格 |
|---|---|
| **主按钮** | `accent` 底 + `outline` 描边 + 底部 2px 深橙 `#B85A1F` 立体边；按下时整体下移 2px、立体边消失（唯一的"动画"） |
| **次按钮** | 透明底 + `text` 描边 |
| **进度条** | 高 12dp，`outline` 槽 + 彩色填充，分段（每 10% 一格）更像素 |
| **任务卡** | 左：24px 图标；中：任务名 + 进度条/计数；右：奖励 chip（战力/金币）或"开始"按钮；完成后盖"已完成"印章 |
| **BOSS 卡** | 与任务卡相同，边框换成 `accent`，四角加铆钉像素 |
| **数值徽章** | 闪电图标 + `gold` 数字，如「战力 3,450」 |
| **对话框（AI 教练）** | 左侧 NPC 头像，右侧 RPG 对话气泡（白边 + 尖角），文字可逐字出现（可选，唯一允许的文字动效） |
| **卷轴面板** | `parchment` 底 + 上下卷轴端头，用于 AI 计划时间线 |
| **底部导航** | 5 格：任务⚔ / 角色⛑ / **＋记录**（中间凸起的橙色大按钮）/ 奖励📦 / 计划📜，选中格加 `accent` 边框 |
| **识别结果行** | 图标 + 名称 + 可编辑数值框 + 置信度标签（绿「准确」/ 橙「请核对」）|
| **状态效果卡** | 类似 RPG Buff/Debuff：图标 + 状态名（疲惫/精力充沛）+ 对任务和战力的影响 |

## 5. 动画原则（尽量简单）

只允许以下 3 种，且都用**帧切换**，不用补间：
1. 按钮按下：下移 2px（1 帧）。
2. 数值增加：战力/金币数字直接跳变 + 旁边出现 `+50` 绿字停留 1 秒后消失。
3. 角色待机：2 帧呼吸（上下 1px），0.5 秒切换一次；可在设置里关闭。

宝箱开启、升级等全部用"静态结算弹窗"（见 `05_quest_complete.png`）代替过场动画。

## 6. 游戏化数值草案（给后续开发参考）

- **战力** = 力量×10 + 耐力×10 + 敏捷×8 + 意志×12 + 装备加成。
  - 力量 ← 力量训练分钟；耐力 ← 有氧 / 步数；敏捷 ← 柔韧、HIIT；意志 ← 连续打卡天数、饮食达标。
- **经验 / 等级**：每个任务给 XP，升级解锁新装备槽、新皮肤。
- **金币**：兑换休息日券、放纵餐券、皮肤（商店可调控"放纵"频率，防止报复性进食）。
- **每周 BOSS**：AI 根据用户薄弱项生成（例如"甜食魔王"= 一周不喝含糖饮料）。
- **体重里程碑**：每降一个目标节点开一次传说宝箱。

## 7. 技术架构概要（下一步）

- **客户端**：Kotlin + Jetpack Compose（自定义像素主题，`PixelPanel`、`PixelButton`、`PixelProgressBar` 组件）。
- **本地数据**：Room（体重记录、任务、背包、成就）；DataStore 存设置。
- **步数**：Health Connect（读取步数/运动/体重），兼容无谷歌服务的国产机时退回系统计步传感器。
- **大模型**：OpenAI 兼容接口，用户在设置页填 API 地址 / Key / 模型；Key 存在 EncryptedSharedPreferences，不上传。
  - 每日 0 点或首次打开时，把用户画像 + 昨日完成情况 + 体重趋势发给模型，要求返回**固定 JSON**（任务列表、卡路里目标、教练寄语），客户端校验后渲染成任务卡。
- **素材**：像素图标/角色可先用生图 API 出草稿，再人工在 Aseprite 里修整到 16/24/32px 网格。

## 8. 生图工具用法

```bash
# 密钥放在 .env.local（已加入 .gitignore，不要提交）
python3 tools/gen_image.py --prompt "$(cat design/prompts/_style.txt design/prompts/home.txt)" --out design/mockups/01_home.png
```

API 为 OpenAI 兼容格式：`POST {base}/v1/images/generations`，可用模型含 `gpt-image-2`、`gpt-image-2.5-*`、`gemini-3-pro-image` 等（`GET /v1/models` 查看）。接口偶尔断连，脚本已带重试。

## 9. v0.1 评审后的落地规则（网页版）

- **字号**：只有 5 级：`--fs-s` 辅助、`--fs-m` 正文、`--fs-l` 标题、`--fs-xl` 大数字、`--fs-xxl` 特大数字（`--fs-xs` 只是 `--fs-s` 的别名），每级至少大一个网格单位。`web/src/main.tsx` 按设备像素比把每档取整到「12 个物理像素」的整数倍，所以任何屏幕上像素字体都不发糊。页面里不要再写数字字号。
- **图标**：生图原图放在 `design/assets_raw/`，跑 `python3 tools/pixelate_assets.py` 转成 32 格（普通图标）或 64 格（角色、场景）的真像素图，所有颜色映射到下面的共享美术色板。`<Ico>` 会把显示尺寸取整到素材像素的整数倍。页面里不使用 emoji 或文字符号当图标。
- **可点区域**：按钮、Tab、输入框最小 44px。
- **间距**：只用 4 / 8 / 12 / 16px；按钮立体边和按下位移都是 2px。
- **动效**：只保留角色呼吸（1px、0.5 秒一帧），设置里可以关，系统「减少动态效果」也会关。
